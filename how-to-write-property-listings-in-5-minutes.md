## The 3-Phase AI Listing System

### Phase 1: Property Intake (3 minutes)

Before you ask AI to write anything, you need structured data. The key inputs:

- **Property type** (single-family, condo, townhouse, multi-family, land, commercial, manufactured)
- **Key specs** (beds, baths, sq ft, lot size, year built)
- **Unique selling points** (what makes this property stand out? renovated kitchen? lake view? walk to transit?)
- **Target buyer** (young family? empty nester? investor? first-time buyer?)
- **MLS region** (CRMLS, NEAR, CCRMLS, etc. — each has different character limits and format rules)

Don't rely on the listing agent's bullet points. Walk the property yourself and note 5-8 distinctive features that matter to buyers.

> **Example**: Instead of "nice kitchen," note: "2024 quartz countertop refresh, subway tile backsplash, farmhouse sink, gas range — marketed to young professional couple who cook."

### Phase 2: AI Generation with Property-Type Specific Prompts (2 minutes)

This is where most agents stop — and miss the opportunity. Instead of one generic prompt, use **property-type-specific prompts**.

A luxury condo listing needs different language than a fixer-upper. A commercial property listing reads nothing like a first-time-homebuyer listing.

**The formula for any property type:**

```
Act as a senior real estate copywriter. Write a [PROPERTY TYPE] listing description
for [TARGET BUYER PROFILE] at [PRICE RANGE].

Property details:
- [Beds/Baths/SqFt/Lot]
- [Key feature 1]
- [Key feature 2]
- [Key feature 3]
- [Neighborhood/location highlights]

Tone: [luxury/warm/urgent/investment]
Length: [MLS character limit for your region]

Follow the PAS framework:
- Problem: [buyer's pain point this property solves]
- Agitate: [why this property is the right solution]
- Solution: [call to action with urgency]

Include:
- A compelling headline (under 70 characters)
- A body (within MLS character limits)
- 3 social media variants (Facebook, Instagram, Twitter/X)
```

This single prompt structure adapts to **8+ property types** and produces a complete marketing package — MLS listing plus social media posts — in one go.

### Phase 3: Compliance & Polish (2 minutes)

Here's what most AI listing generators get wrong: **Fair Housing compliance.**

Every MLS requires compliance with the Fair Housing Act. Your listing description cannot reference:

- Race, ethnicity, or national origin
- Religion
- Sex or gender
- Familial status (kids/no kids)
- Disability

AI doesn't inherently know these rules. That's why the **compliance check** phase is non-negotiable.

**The compliance checklist:**

1. **Scan for prohibited references**: Search for words like "perfect for," "ideal for," "great for," or "doesn't require" — these can imply a preferred buyer demographic.
2. **Verify no neighborhood references** that could imply racial or economic composition (some regional MLS rules restrict this).
3. **Check flood zone disclosures**: If the property is in a flood zone, this MUST appear in the listing.
4. **Lead paint disclosure**: Properties built before 1978 require a lead-based paint disclosure in the written listing.
5. **HOA details**: If applicable, HOA fees, rules, and amenities must be accurately stated.
6. **Region-specific format**: CRMLS allows up to 8,000 characters. CCRMLS allows 4,000. NEAR has different formatting rules.

**Bonus: Multi-Platform Output**

A single MLS listing should also generate:
- **Facebook post**: Casual, photo-focused, 150-300 words, with hashtags
- **Instagram caption**: Visual-first, emoji-friendly, under 2,000 characters
- **Email blast**: More detailed, with embedded MLS link, for your active buyer list

Getting all 4 formats (MLS + 3 social/email variants) from one property tour used to take half a day. With this system, **it takes 5-7 minutes.**
